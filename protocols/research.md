# Protocol — Research

1. State the question and what would constitute an answer.
2. Separate: verified facts (with source) / reasonable inferences / open hypotheses.
3. Prefer primary sources (official docs, source code, papers); record version + date.
4. Cross-check important claims against a second source when feasible.
5. Never fabricate citations, URLs, benchmarks, or quotes.
6. Deliver a concise findings summary with confidence levels and gaps.
