# Protocol — Project Planning

1. Write the goal as acceptance criteria (testable statements).
2. Inventory components, dependencies, and constraints from the actual repo/environment.
3. Decompose into ordered implementation steps, each with a verification method.
4. Identify top risks and their fallbacks.
5. Produce the plan as a working checklist; begin execution immediately after.
6. Re-plan when evidence contradicts assumptions — plans serve the work, not vice versa.
